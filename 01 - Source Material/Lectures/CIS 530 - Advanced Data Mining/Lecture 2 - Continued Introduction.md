## Notes

- Link analysis ranking is when the pages are ranked according to importance (authoritativeness) in the graph
	- A page gains authority if linked to by another page
- Exploratory analysis --> trying to understand and describe the data with simple metrics and questions
- Data mining draws ideas from machine learning/AI, statistics, and database systems
	- Can be thought of as the inference of models or queries that examine large amounts of data
- Data mining is a confluence of multiple disciplines
	- Machine learning, pattern recognition, statistics, algorithms, distributed computing etc.
---

- Analysis pipeline: data processing --> data mining --> post processing
	- Real data tends to be noisy, incomplete, and inconsistent 
- Data quality problems
	- Noise and outliers
		- Noise: purely useless data, not a valid data point
		- Outlier: varying from the general distribution
	- Missing values
	- Duplicate data
- Sampling
	- Employed for data selection
	- Obtaining the entire set of data of interest is too expensive or time consuming
	- Sample needs to be representative of the complete dataset; needs to have approximately the same property (of interest) as the original set of data
	- Types: simple random sampling, sampling without replacement, sampling with replacement, stratified sampling
---

- A column vector has dimension n by 1
	- The transpose operation flips the column to a row vector
- Purpose of vectors
	- Representing an offset in 2D or 3D space
	- Points are just vectors from the origin
	- Can also have vectors that don't have a geometric interpretation like pixels or gradients at an image keypoint
- Matrix operations
