# Basic Data Mining


### Big Idea
- Data mining: use of efficient techniques for the analysis of very large collections of data and the extraction of useful and possibly unexpected patterns in data.
- Data is comprised of transaction data, document data, network data, genomic sequences, behavioral data, and environmental data.
	- Each of these data types contains their own unique characteristics.
	- I.e., transaction data refers to the data collected by Walmart, Amazon; containing information about your transaction.
- Data can be defined as categorical or numeric.

### Basic Data Structure
- In general, data is a collection of attributes used to describe a specific object.
- But what is an attribute?
	- An attribute can be any kind of property or characteristic of an object.
	- A collection of these attributes describe a specific object/data point.
	- Examples: eye color of a person, height, weight, their job, and more.
- A dataset has the following definitions:
	- Size: simply the number of objects.
	- Dimensionality: number of attributes.
	- Sparsity: Proportion of unpopulated object-attribute pairs.

### Categorical vs. Numeric Data
- Data can either by categorical (qualitative) or numeric (quantitative)
- Categorical data is non-numeric, and has two sub-tyes
	- Nominal has no order or comparison. 
		- Meaning, you cannot directly say one value is greater than another value. Ex. single is not greater than married.
	- Ordinal can be ordered and compared.
		- Bad < fair < good, but, they do not have a direct numerical meaning. Cannot do good-bad.
- Numeric is also known as quantitative data.
	- Dates, temperatures, time, length, and counts are all examples of numerical data.
	- It also has two types; discrete (such as counts of chairs) or continuous (such as temperature values).
